# Sistema Operacional Pessoal

Sistema pessoal criado no Notion para organizar tarefas, prioridades, compromissos, planejamento semanal e acompanhamento da produtividade.

## Descrição do sistema

O sistema utiliza uma Central única para registrar:

- Tarefas;
- Compromissos;
- Metas semanais;
- Revisões semanais e mensais;
- Prazos;
- Próximos passos;
- Estimativas de tempo;
- Técnicas de produtividade utilizadas.

O funcionamento segue o ciclo:

> Capturar → Organizar → Planejar → Executar → Revisar

A página principal contém as instruções de uso e a base **Central — Sistema Operacional Pessoal**, que concentra todas as informações.

## Ferramentas utilizadas

### Notion

Utilizado para armazenar, organizar e visualizar as atividades.

### Banco de dados da Central

A Central possui os seguintes campos:

| Campo | Função |
|---|---|
| Item | Nome da tarefa, compromisso, meta ou revisão |
| Status | Not started, In progress, Done ou Archived |
| Tipo | Tarefa, Compromisso, Meta semanal ou Revisão |
| Prioridade | P1 — Essencial, P2 — Importante ou P3 — Se possível |
| Data | Prazo, data do compromisso ou data planejada |
| Área | Trabalho, Estudos, Saúde, Pessoal ou Finanças |
| Estimativa (min) | Tempo aproximado para concluir |
| Técnica | Timeboxing, Pomodoro, Regra dos 2 minutos ou Sem técnica |
| Concluído | Indica se o item foi finalizado |
| Notas / próximo passo | Contexto, instruções ou próxima ação |

### Visualizações

- **Central:** visão geral de todos os itens.
- **Foco — hoje e próximos 7 dias:** atividades que precisam de atenção imediata.
- **Kanban por status:** organização visual por etapa.
- **Calendário de compromissos:** prazos, reuniões e eventos.
- **Painel de produtividade:** acompanhamento do volume e do andamento das atividades.

### Notion AI

Utilizado para:

- Transformar anotações em tarefas;
- Resumir reuniões e textos;
- Identificar decisões e próximos passos;
- Criar sugestões de planejamento semanal;
- Analisar atrasos, excesso de compromissos e gargalos.

### Técnicas de produtividade

O sistema utiliza principalmente:

- **Timeboxing:** reservar um bloco de tempo específico para uma atividade.
- **Pomodoro:** trabalhar em ciclos de 25 minutos de foco e 5 minutos de pausa.
- **Regra dos 2 minutos:** executar imediatamente tarefas muito rápidas.

## Fluxo de organização

### 1. Capturar

Registre qualquer demanda nova na Central, mesmo que ainda não esteja totalmente organizada.

Exemplos:

- Responder e-mail;
- Estudar para uma prova;
- Marcar consulta;
- Preparar apresentação;
- Comprar material;
- Participar de reunião.

### 2. Esclarecer

Transforme a demanda em uma ação clara, começando preferencialmente com um verbo.

Evite:

> Apresentação

Prefira:

> Preparar os cinco primeiros slides da apresentação

### 3. Classificar

Preencha:

- Tipo;
- Área;
- Prioridade;
- Data;
- Estimativa;
- Técnica de produtividade.

### 4. Planejar

Escolha no máximo três prioridades P1 para cada dia.

Distribua as tarefas no calendário de acordo com:

- Tempo disponível;
- Energia necessária;
- Prazos;
- Compromissos já existentes.

### 5. Executar

Altere o status para **In progress** quando começar.

Use:

- Timeboxing para tarefas com duração definida;
- Pomodoro para atividades de concentração;
- Regra dos 2 minutos para ações rápidas.

### 6. Concluir

Ao finalizar:

1. Altere o status para **Done**.
2. Marque a caixa **Concluído**.
3. Registre o resultado ou próximo passo nas notas.
4. Caso exista uma nova ação, crie uma nova tarefa.

### 7. Revisar

Faça revisões periódicas para evitar acúmulo de tarefas sem data ou sem prioridade.

## Como utilizar a solução

## Uso diário

### Início do dia

1. Abra a visualização **Foco — hoje e próximos 7 dias**.
2. Confira os compromissos no calendário.
3. Escolha até três prioridades P1.
4. Reserve blocos de tempo para as tarefas mais importantes.
5. Comece a primeira tarefa e altere o status para **In progress**.

### Durante o dia

1. Registre novas demandas na Central.
2. Evite organizar excessivamente cada entrada no momento da captura.
3. Use a Regra dos 2 minutos para tarefas rápidas.
4. Use Pomodoro ou Timeboxing para tarefas maiores.
5. Atualize o status conforme o andamento.

### Final do dia

1. Marque as tarefas concluídas como **Done**.
2. Marque o campo **Concluído**.
3. Reagende somente o que ainda for importante.
4. Elimine ou arquive tarefas que perderam relevância.
5. Registre os próximos passos das tarefas incompletas.

## Uso semanal

Uma vez por semana:

1. Esvazie a INBOX.
2. Revise as tarefas atrasadas.
3. Confira os compromissos da semana seguinte.
4. Escolha até três resultados principais.
5. Crie tarefas menores para cada resultado.
6. Distribua as tarefas no calendário.
7. Reserve tempo para imprevistos.
8. Atualize a entrada **Planejamento semanal — escolher 3 resultados**.
9. Faça a **Revisão semanal — fechar ciclo**.

### Exemplo de resultado semanal

> Finalizar o trabalho da disciplina.

Tarefas relacionadas:

- Pesquisar referências;
- Criar a estrutura do trabalho;
- Escrever a primeira versão;
- Revisar o conteúdo;
- Enviar o trabalho.

## Uso mensal

No fim de cada mês:

1. Revise os itens concluídos.
2. Identifique tarefas adiadas várias vezes.
3. Analise o volume de compromissos.
4. Verifique quais áreas receberam mais ou menos atenção.
5. Escolha de um a três focos para o próximo mês.
6. Atualize a entrada **Revisão mensal — ajustar direção**.

## Uso da Inteligência Artificial

### Organizar anotações

Use o seguinte prompt:

> Converta este texto em tarefas acionáveis. Para cada tarefa, sugira um título iniciado por verbo, prioridade, prazo, estimativa em minutos, área e técnica de produtividade. Separe compromissos de tarefas e sinalize dúvidas.

### Resumir reuniões

> Resuma este conteúdo em decisões, tarefas, responsáveis, prazos, riscos e perguntas em aberto. Não invente informações.

### Planejar a semana

> Com base nos itens da Central, proponha uma semana realista com no máximo três resultados principais, blocos de foco, compromissos fixos e margem para imprevistos. Indique o que deve ser adiado ou eliminado.

### Fazer uma revisão

> Analise as tarefas concluídas, atrasadas e sem data. Identifique gargalos, excesso de compromissos e próximos passos. Sugira mudanças práticas para a próxima semana.

A IA deve ser utilizada como apoio. Sempre revise as sugestões antes de criar, alterar ou concluir tarefas.

## Regras de prioridade

### P1 — Essencial

Atividade com prazo próximo, alto impacto ou consequência relevante.

### P2 — Importante

Atividade que contribui para objetivos, mas pode esperar.

### P3 — Se possível

Atividade opcional, de baixo impacto ou que pode ser feita quando houver disponibilidade.

Regra recomendada:

> Não tenha mais de três prioridades P1 por dia.

## Indicadores de produtividade

Durante a revisão semanal, acompanhe:

- Quantidade de itens concluídos;
- Quantidade de itens atrasados;
- Número de prioridades P1 concluídas;
- Taxa de conclusão;
- Tempo estimado planejado;
- Quantidade de tarefas reagendadas;
- Número de compromissos da semana;
- Entrega dos três resultados principais.

## Princípios do sistema

1. Tudo que exige ação deve entrar na Central.
2. Toda tarefa deve ter um próximo passo claro.
3. Compromissos devem ser registrados assim que forem confirmados.
4. A agenda deve conter espaço para imprevistos.
5. Nem toda tarefa precisa ser prioridade.
6. A revisão semanal é mais importante do que o preenchimento perfeito.
7. Se o sistema ficar pesado, reduza categorias e arquive o que perdeu relevância.
8. O objetivo do sistema é liberar atenção, não criar mais trabalho.
